# Changelog XLS Generator

Все изменения фиксируются здесь. Формат: [версия] - [дата] - [описание].

## [v1.1.0] - 2026-05-12
- Добавлена пакетная обработка файлов (до 10 файлов одновременно).
- Новый API endpoint `/api/process-files` для обработки нескольких файлов.
- Возврат результатов в ZIP-архиве с отчётом `changes.json`.
- Обновлён UI для загрузки нескольких файлов.
- Добавлена зависимость `archiver` для создания ZIP.

## [v1.0.0] - 2026-05-12
- Базовая функциональность: загрузка, обработка и скачивание Excel-файлов.
- Интеграция с OpenRouter API.
- Поддержка моделей: DeepSeek, GPT-4o, Claude.
- UI на React + TypeScript.

## [v0.1.0] - 2026-04-01
- Прототип с базовым анализом и обработкой файлов.
