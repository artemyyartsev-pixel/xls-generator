# Roadmap проекта XLS Generator

## Видение
Стать ведущим AI-инструментом для автоматизации Excel-задач, позволяющим нетехническим пользователям обрабатывать файлы без VBA и ручного труда.

## Краткосрочные цели (3-6 месяцев)
- **Пакетная обработка**: Поддержка нескольких файлов и архивов.
- **Шаблоны**: Предустановленные сценарии для типовых задач.
- **История изменений**: Откат и аудит изменений.

## Среднесрочные цели (6-12 месяцев)
- **Пользовательские аккаунты**: История, сохранение файлов.
- **Интеграции**: API для внешних систем (Google Sheets, etc.).
- **Мобильная версия**: PWA для мобильных устройств.

## Долгосрочные цели (1-2 года)
- **Расширенная аналитика**: AI-анализ данных в файлах.
- **Коллаборация**: Совместная работа над файлами.
- **Энтерпрайз-функции**: Безопасность, аудит, compliance.

## Метрики успеха
- Количество пользователей: 10k+.
- Уровень удовлетворённости: >4.5/5.
- Время обработки файла: <5 сек.

## Риски и зависимости
- Зависимость от OpenRouter API.
- Конкуренция с другими AI-инструментами.
- Технические ограничения (размер файлов, LLM-лимиты).
