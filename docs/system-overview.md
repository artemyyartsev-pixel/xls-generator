# Система XLS Generator

## Обзор

`xls-generator` — это AI-инструмент для автоматической обработки Excel-файлов. Пользователь загружает `.xlsx`, `.xls` или `.xlsm`, описывает задачу на естественном языке, и система возвращает изменённый файл без VBA и ручного вмешательства.

Цель проекта — дать нетехническим пользователям возможность быстро выполнять:
- расчётные формулы и вычисления
- форматирование и выделение данных
- фильтрацию и удаление дубликатов
- генерацию итоговых строк и сводных отчётов
- создание графиков и визуальных представлений

## Архитектура

### Фронтенд
- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

Основная логика находится в `client/src/pages/Home.tsx`.
Фронтенд позволяет пользователю:
- загрузить файл
- описать задачу
- выбрать модель
- запустить выполнение
- скачать результат

### Бэкенд
- Node.js 20 LTS
- Express.js
- multer для обработки multipart-загрузок
- `server/routes.ts`

Основные API:
- `POST /api/analyze-file` — анализ структуры Excel-файла
- `POST /api/process-file` — генерация Python-кода, выполнение и возврат результата

### Python / Excel
- `server/xlsProcessor.py`
- `openpyxl` для работы с `.xlsx` и `.xlsm`
- `xlrd` + конвертация для `.xls`
- AI-генерируемый код исполняется в изолированной среде с ограниченным набором глобальных функций

## Поток обработки

1. Пользователь загружает файл.
2. Файл сохраняется во временной директории ОС.
3. `/api/analyze-file` вызывает `python3 server/xlsProcessor.py analyze`.
4. Python возвращает структуру:
   - листы
   - столбцы
   - количество строк
   - образец данных
5. Бэкенд формирует промпт и отправляет его в OpenRouter.
6. Модель возвращает Python-код.
7. Бэкенд вызывает `python3 server/xlsProcessor.py execute`.
8. Код применяется к файлу, результат сохраняется.
9. Пользователь получает изменённый файл.

## Интеграция LLM

Проект использует OpenRouter API для доступа к моделям:
- DeepSeek V3
- DeepSeek R1
- GPT-4o mini
- Claude Sonnet
- и дополнительные модели через OpenRouter

Ключ конфигурации хранится в `OPENROUTER_API_KEY`.

## Временные файлы и безопасность

- `multer` сохраняет файлы в `os.tmpdir()`.
- файлы копируются с правильным расширением для `openpyxl`.
- для `.xls` выполняется конвертация в `.xlsx`.
- временные файлы удаляются после обработки.
- максимальный размер загружаемого файла — 10 МБ.

## Требования

- Node.js 20 LTS
- Python 3.8+
- `openpyxl`
- `xlrd`

Запуск:

```bash
npm install
cp .env.example .env
# Указать OPENROUTER_API_KEY
npm run dev
```

## Текущие ограничения

- пакетная обработка файлов реализована (до 10 файлов)
- поддержка ZIP/RAR-архивов отсутствует
- нет пользовательских аккаунтов
- отсутствует очередь фоновых задач
- ограничение по размеру файла 10 МБ
