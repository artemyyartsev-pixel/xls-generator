# User Stories XLS Generator

## Формат
Как [роль], я хочу [функциональность], чтобы [польза].

## Текущие User Stories

### US-001: Обработка одного файла
Как пользователь Excel, я хочу загрузить файл и описать задачу на русском, чтобы получить изменённый файл без VBA.

**Критерии приёмки**:
- Загрузка .xlsx/.xls/.xlsm.
- Ввод задачи (например, "добавить колонку Прибыль").
- Выбор модели.
- Скачивание результата.

### US-002: Пакетная обработка
Как бухгалтер, я хочу обработать несколько файлов одним заданием, чтобы сэкономить время.

**Критерии приёмки**:
- Загрузка нескольких файлов.
- Применение одной задачи ко всем.
- Получение ZIP с результатами.

### US-003: Поддержка архивов
Как аналитик, я хочу загрузить ZIP с файлами, чтобы не загружать каждый по отдельности.

**Критерии приёмки**:
- Распаковка ZIP/RAR.
- Обработка Excel-файлов внутри.
- Возврат ZIP с изменениями.

### US-004: История изменений
Как пользователь, я хочу видеть, что изменилось в файле, чтобы понять результат.

**Критерии приёмки**:
- JSON с изменениями.
- UI для просмотра лога.
- Возможность отката.
