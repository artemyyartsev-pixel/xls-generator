# Бэклог проекта XLS Generator

## Описание
Этот файл содержит текущий бэклог задач для проекта `xls-generator`. Задачи приоритизируются по бизнес-ценности, сложности и зависимости. Обновляется Business Analyst агентом ежедневно.

## Формат задач
- **ID**: Уникальный идентификатор (например, BG-001).
- **Название**: Краткое описание.
- **Приоритет**: High/Medium/Low.
- **Статус**: Backlog/In Progress/Done.
- **Критерии приёмки**: Что должно быть выполнено.
- **Оценка**: Story Points (1-8).
- **Зависимости**: Другие задачи.

## Текущие задачи

### BG-001: Пакетная обработка файлов
- **Приоритет**: High
- **Статус**: Done
- **Описание**: Добавить возможность обрабатывать несколько Excel-файлов одним заданием.
- **Критерии приёмки**:
  - Загрузка нескольких файлов.
  - Применение одного задания ко всем.
  - Возврат ZIP с результатами.
- **Оценка**: 5
- **Зависимости**: Нет

### BG-002: Поддержка ZIP/RAR архивов
- **Приоритет**: Medium
- **Статус**: Backlog
- **Описание**: Разрешить загрузку ZIP или RAR с Excel-файлами.
- **Критерии приёмки**:
  - Распаковка архива.
  - Обработка только Excel-файлов.
  - Возврат ZIP с результатами.
- **Оценка**: 3
- **Зависимости**: BG-001

### BG-003: История изменений и откат
- **Приоритет**: Medium
- **Статус**: Backlog
- **Описание**: Сохранять историю изменений по файлу и позволять откат.
- **Критерии приёмки**:
  - Лог изменений в JSON.
  - UI для просмотра истории.
  - Кнопка отката.
- **Оценка**: 4
- **Зависимости**: Нет

### BG-004: Шаблоны и пресеты
- **Приоритет**: Low
- **Статус**: Backlog
- **Описание**: Предустановленные шаблоны для типовых задач.
- **Критерии приёмки**:
  - Список шаблонов в UI.
  - Применение шаблона к файлу.
- **Оценка**: 2
- **Зависимости**: Нет
